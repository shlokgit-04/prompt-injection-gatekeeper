About

A security/decision layer for AI agents, built for the AWS Agent Experience Hackathon 2026.

What it does

Agents can be hijacked: an untrusted document, email or web page can carry hidden instructions that make the agent leak data or take actions the user never asked for. This layer sits at the tool boundary. Every proposed tool call is evaluated before it executes: PROCEED runs and is audited, CONFIRM parks for a human in the approval queue, DENY never reaches the real tool. On any failure the layer fails closed.

The decision layer

The intended engine is Strands Decider 2B, a 2B-parameter decision model served locally, answering seven typed yes/no questions per call with calibrated probabilities, mapped onto the three actions by a policy with configurable thresholds. Where the model server is not attached (this hosted demo), a clearly labeled deterministic signature engine takes over: it flags exfiltration markers, unnamed recipients, ungrounded queries and instruction directives hidden in documents, and everything it cannot classify fails closed to human approval. Every decision records which engine produced it; the fallback never presents itself as the model.

Security model

Real accounts with bcrypt-hashed passwords and signed sessions; per-user data isolation on every endpoint; the tool registry holds only gated wrappers, so there is no path from a tool choice to a real function that bypasses the gate; append-only audit log with secret redaction; rate limits; read-only demo database; the demo mail tool writes to an internal outbox only. No system is 100% secure; this layer constrains a class of prompt-injection failures and logs everything it does.
